# medialane-io/.github

Organization profile and shared community files for [Medialane](https://medialane.io).

The public organization page is [`profile/README.md`](profile/README.md).

## Contributing

Contributions are welcome in every Medialane repository. To suggest a feature or fix:

1. Fork the repository.
2. Create a branch (`git checkout -b feature/your-idea`).
3. Commit your changes.
4. Open a pull request describing what it changes and why.

For larger ideas, open an issue first so we can discuss them together.
